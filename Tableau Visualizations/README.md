# Data Visualization Compilation (Tableau)

An interactive Tableau dashboard analyzing aimed to document basic Tableau functions across 
multiple views. It uses a parameter-based navigation letting viewers switch between 
worksheets without leaving the dashboard.

**[View live on Tableau Public](https://public.tableau.com/views/DataVisualizationCompilation/RegionAnalysis?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**
